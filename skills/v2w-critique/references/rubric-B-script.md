# Rubric B — script (brief.md)

Score 1–5. 5 = nothing to change · 3 = usable with one clear fix · 1 = wrong or missing.
Also apply the topic-specific checks listed in `refs/refcard.md` → Synthesis (score them under B7).

| id | item | blocking | what 5 looks like |
|---|---|---|---|
| B1 | Hook | blocking | ≤ 23 characters (CJK) / ≤ 6 words; states a conflict; understandable on mute within 3 s. |
| B2 | Explanation order | blocking | Each beat answers the question the previous one raised; nothing is used before it is shown. |
| B3 | Payoff computed, not asserted | blocking | The conclusion is shown with the proof numbers (needed vs available, used vs idle), around 2/3–3/4 of the runtime. |
| B4 | Claims consistent and sourced | blocking | Every on-screen number appears in principle.md / Claims + sources with the same value. |
| B5 | One message per beat | — | Each beat carries one message; something new appears every 2–3 s; no beat > 4 s in the peak act. |
| B6 | Term policy | — | Each term is introduced as "what it does → its name"; ≤ 4 terms in total. |
| B7 | Uses the references | — | Settles a confusion the references leave open, or avoids their common mistake; borrows devices, not wording. |
| B8 | Closing line | — | One sentence worth a screenshot, restating the mechanism, not a slogan. |
| B9 | Density | — | Fits the length: neither padded nor four minutes squeezed into 45 s. |
