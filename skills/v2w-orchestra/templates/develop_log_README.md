# develop_log

Private, raw debugging notes for this project: tool errors, failed attempts,
environment quirks, things you tried and dropped. Keep them here, not in the
public skill repo.

When a note turns into a reusable rule, distil it (no paths, accounts, or
piece content) into the skill repo — see `docs/maintaining.md` there — and
leave a back-pointer here, e.g. `→ promoted to v2w shared/pitfalls.md (v0.2.0)`.
